```
├─ Large touch targets
└─ Compact spacing

Tablet (768px - 1024px)
├─ 2-column grids
├─ Medium spacing
├─ Horizontal nav (if space)
└─ Adapted layouts

Desktop (> 1024px)
├─ 3-column grids
├─ Large typography
├─ Generous spacing
├─ Full navigation
└─ Wide layouts
```
